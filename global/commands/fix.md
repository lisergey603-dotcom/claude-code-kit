Проблема: $ARGUMENTS

1. Воспроизведи или локализуй ошибку: найди место в коде по тексту ошибки, стектрейсу, логам. Для падений в GitHub Actions — `gh run list` и `gh run view --log-failed`.
2. Найди **настоящую причину**, а не симптом. Коротко объясни её простыми словами.
3. Исправь минимальной правкой. Не переписывай соседний код.
4. Проверь: сборка/тесты/запуск — что есть в проекте.
5. Итог в 3 строки: причина → что исправлено → как проверено.

Если причин несколько возможных и проверить нельзя — перечисли их по вероятности и предложи, что проверить первым.
